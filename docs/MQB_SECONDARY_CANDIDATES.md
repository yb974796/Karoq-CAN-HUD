# opendbc 更多 MQB 候選 ID（暫不接入 UI，也未加入 12-ID 動態 probe）

對照相同來源 `vw_mqb.dbc` 與 Volkswagen `carstate.py`：

| ID | DBC 訊框 | 預計用途 | 暫未解碼原因 |
|---|---|---|---|
| `0x086` | `LWI_01` | 方向盤角度與角速度 | 不屬目前優先 HUD 狀態；若要顯示轉角，需驗證 QBit/符號位 |
| `0x117` | `ACC_10` | FCW/AEB 釋放訊號 | AEB 安全敏感，本機只能研究訊號，不可控制 |
| `0x121` | `Motor_20` | 油門踏板原始值 | HUD 目前不要求油門 % |
| `0x3DB` | `Gateway_72` | 網關訊息、車身狀態 | 欄位多且跨車型變化，需 Karoq 再確認 |
| `0x6B8` | `Kombi_03` | 儀表種類與變體 | 裝車前由實際接收與版本判定 |

**重要**：openpilot `Bus.pt`, `Bus.cam`, `Bus.ext` 並非保證分別等於車輛實體 CAN 腳位所在線路。單路 ESP32 TWAI 只能知道目前這組線收到哪些訊框。不能根據 missing ID 推定其物理網段或硬體不存在。

交通限速標誌（非紅綠燈）及導航指引目前不直接從上述 17 個 ID 取得完整圖示；須另研究 VC↔車機 BAP / 其他來源且保留資訊有效性檢查。
